RD Panel Relay Agent (hbbr + rdpanel agent) deployed.

Release name: {{ .Release.Name }}
Namespace:    {{ .Release.Namespace }}

{{- if .Values.service.enabled }}
{{- if eq .Values.service.type "LoadBalancer" }}
To obtain the public IP / hostname for RustDesk clients:
  kubectl get svc -n {{ .Release.Namespace }} {{ include "rdpanel-relay-agent.fullname" . }} -w
{{- else if eq .Values.service.type "NodePort" }}
Relay is exposed via NodePort:
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "rdpanel-relay-agent.fullname" . }})
  echo "Relay address: $NODE_IP:$NODE_PORT"
{{- end }}
{{- end }}

Agent status:
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "rdpanel-relay-agent.name" . }} -f
